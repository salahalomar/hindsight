hindsight / playground

A recording, not a replay. Paste a Java class with a main method. It is compiled, run in a fresh JVM with the agent attached, and whatever it did on the way to failing is shown on the right. hindsight records execution, so the snippet has to actually run.

This compiles and runs whatever you paste. That is what a debugger playground is. The demo binds to 127.0.0.1 for exactly this reason — never expose it on a network.

Your snippet is compiled into package snippet, which is the package the agent is pointed at. Any package line you write is replaced, because a class in the default package can never match a package prefix and would record nothing at all.
